↓ install_byte.txt WINDOWS x64

Installing Byte

  1. Download Byte-v1.0.0-Windows-x64.zip from the official release.
  2. Extract the entire ZIP into a normal writable folder.
  3. Open the extracted application folder.
  4. Double-click Byte.exe.
  5. Say hello to your newest desktop resident. ♡
Important: Keep all extracted application files together. Byte is portable and includes Electron, so you don't need Node.js to run the Windows download.

Byte is currently unsigned. Windows may display a security warning. Download only from the official release, verify the checksum if desired, and run it only if you trust the file.

Verifying the download

Windows PowerShell can calculate the ZIP's SHA256 hash. Compare the result against the official Byte-v1.0.0-SHA256SUMS.txt release attachment. 

Get-FileHash ".\Byte-v1.0.0-Windows-x64.zip" -Algorithm SHA256

Run this command from the folder containing the ZIP, or replace the quoted path with the ZIP's full location.

? help_and_troubleshooting.txt FAQ

Need a little help?

Can I run Byte without installing Node.js?

Yes. The Windows ZIP includes a packaged Electron app. Node.js is only needed for development from source.

Why is Windows showing a warning?

Byte.exe is unsigned. Download it from the official CyberStudios release and verify the file's SHA256 checksum if desired. Only run files you trust.

What if Byte disappears offscreen?

Open his room and choose Bring Byte home. This returns him to a safe position on your primary monitor without resetting his other progress.

How do I close Byte completely?

Use Quit Byte, the window's close control, or the desktop cat's × control.

Where is Byte's saved data?

Byte stores local state at %APPDATA%\CyberStudios\Byte\byte-state.json. Close Byte before manually editing or renaming it.

Does Byte use generative AI?

No. His Talk feature uses predefined local responses. Byte doesn't need an online AI provider.

♡ privacy_and_care.txt LOCAL-FIRST

A companion, not a chore.

Byte is designed as a local-first desktop pet. He doesn't require an account, online chatbot, tracking service, or cloud connection.

His care stats and preferences save on your computer. His needs don't decay while you're away, and he doesn't have pet-death or punishment mechanics.

CyberStudios creates many different projects. Byte's privacy and gameplay characteristics apply to Byte.exe, not automatically to every future CyberStudios application.
