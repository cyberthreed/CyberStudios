A desktop with a little personality

Elsewhere OS is my love letter to the desktops that felt like places. Blue glass, clear skies, your own wallpaper and sounds, and windows you can move around until the whole thing feels like yours.

The project is a Windows 11 desktop shell in development. Its companion app, Elsewhere Messenger, has its own guide and can run separately.

What’s inside

Your desktopStart menu, taskbar, windows, wallpaper and sound settings.Elsewhere MessengerA buddy list and a little window for the people you want to talk to.Elsewhere AccountsOne identity for Messenger and future apps that support it.

Getting started

  1. Start with the Elsewhere OS repository to see what is available for Windows 11.
  2. Want the chat app? Open the Messenger guide for the beta, account setup, and integrations.
  3. For questions about installation or the project, use the FAQ below or email elsewhere.os.info@gmail.com.

Frequently asked questions

Is Elsewhere OS an operating system?

It is a desktop shell project for Windows 11. Windows still runs underneath, so there is no separate operating system to install or dual boot.

What is Elsewhaero?

The Elsewhere visual style. Think sky-blue glass, white light, little flashes of lime, and a butterfly with clouds in its wings. It is our little branch of Frutiger Aero.

Where can I get Elsewhere OS?

Follow the Elsewhere OS repository for official releases and project news. A repository page or a source ZIP is not a Windows installer.

Is the full shell finished?

The shell is in development. The project has explored a Start menu, taskbar, windows, and desktop settings. Availability depends on the build you have.

Can I use it on Windows 10, macOS, or Linux?

Windows 11 is the target for the desktop shell. Other operating systems and Windows versions are unverified.

Do I need the shell to run Messenger?

Messenger has its own Windows app and can run on its own. You can read its guide and make an account without setting up the shell.

Will my Elsewhere account work across apps?

Elsewhere Accounts are designed to be shared by apps that integrate them. Messenger is the first account client. An account does not automatically sign you in to apps that have not integrated it yet.

Do I need internet for the desktop?

Local shell features and the desktop look are separate from online features. Account signup, verification, and connected services need internet.

What can I personalize?

The shell prototype includes controls for wallpaper, color, sound, volume, display name, and full screen. Check your build for the available options.

Is Elsewhere affiliated with Microsoft?

Elsewhere is an independent CyberStudios project inspired by the desktop interfaces we grew up with.

Where can I follow development or suggest something?

The GitHub repository is the project home. For a bug, include the build, your Windows version, and the steps that showed the issue.
