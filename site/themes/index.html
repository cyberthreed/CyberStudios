03 / make yourself at home

One small change. A whole new atmosphere.

⌘ VS Code · the eight VSIX themes

  1. Download the installer ZIP above and extract it.
  2. In VS Code, open Extensions, then … → Install from VSIX…
  3. Choose the theme’s .vsix file.
  4. Run Preferences: Color Theme from the Command Palette and select its name.

Cotton Candy’s Soft & Vivid settings presets follow their separate guide.

✿ Blender · Soft & Vivid

  1. Download your chosen .xml file above.
  2. Open Edit → Preferences → Themes in Blender.
  3. Choose Install… and select the XML.
  4. Save Preferences if automatic preference saving is off.

The HTML page is a preview. The XML is the file Blender installs.
