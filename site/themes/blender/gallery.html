Make yourself at home

Pick one. Open a new window.

  1. Download an XML preset using its button above.
  2. In Blender, open Edit → Preferences → Themes → Install….
  3. Select the XML file. Save Preferences if automatic saving is off.

Native import/export checked with Blender 5.2.3 LTS. Other versions are untested. The tools belong to the source collection; only XML files are needed to install a theme.
