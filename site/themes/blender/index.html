This HTML works offline and includes both complete themes. Blender installs the downloaded XML file.

  1. 1
    Pick your flavor.

    Soft keeps the gentler syntax colors. Vivid brings richer violet and orchid to text and node headers. Both keep the same pastel interface.

  2. 2
    Open Edit → Preferences → Themes.

    Choose Install…, then select the Soft or Vivid XML file you downloaded.

  3. 3
    Let the daydream settle in.

    The theme applies immediately. Save Preferences if automatic preference saving is turned off.
