⌘ installation.guide GETTING STARTED

Let's get you installed. ♡

01 // Download the add-on

Download the packaged CyberStudios Theme Switcher ZIP from the official GitHub release. Keep the ZIP file intact.

02 // Open Blender Preferences

In Blender, navigate to Edit → Preferences → Add-ons. Open the add-ons menu and select Install from Disk...

03 // Install and enable

Select the downloaded ZIP file, install it, and enable CyberStudios Theme Switcher.

04 // Pick your first theme

Go to Preferences → Themes and open the CyberStudios Theme Switcher menu to choose a theme.

For the complete manager, open the add-on entry in Blender's Add-ons preferences.

♡ Compatibility note: The add-on declares Blender 4.2 or newer as its minimum version and was reported tested on Blender 5.2.3 LTS. Save Blender's preferences if you want your selected appearance to persist after restarting.
☁ theme_manager.help USER GUIDE

Make yourself at home.

♡ Add a theme from code

Copy valid Blender theme XML to your clipboard, enter a name in the add-on preferences, click Paste Theme Code, then Save Theme.

Your new preset will appear under My Saved Themes.

✿ Import an existing theme

Select Import XML File, choose a compatible .xml file, confirm its name, and save it to your personal collection.

⇩ Export a theme

Find the theme in the manager and select its Export icon to save a copy of its XML file to your computer.

☁ Keep your favorites

Use Save Current Theme As... to preserve the theme Blender is currently using.

Personal themes are stored in the add-on's user data directory, separately from its bundled themes.

✧ The code-paste feature accepts Blender theme XML, not arbitrary Python scripts. Only personal saved themes can be deleted through the manager.
