Know what was actually checked.

ModManifest is an open-source, read-only command-line utility for inspecting, validating, and auditing game mod packages for The Sims 4 and inZOI.

Not everything inside a mod package can be verified. ModManifest tells you what it found, what it only observed, and where its knowledge ends. It never extracts, executes, modifies, or uploads anything.

v0.1.1 · WINDOWS · LINUX · macOS · PYTHON 3.11+
🎮 modmanifest.games SIMS 4 · inZOI

Two games, honest scope ♡

Commands

modmanifest inspect PATH [--json]
modmanifest validate PATH --game sims4|inzoi [--json]
modmanifest audit-ai PATH [--json]
modmanifest --version

PATH is a folder, .zip, .ts4script, or .package.

CommandRuns
inspectArchive safety, game recognition and validation, AI metadata audit.
validateArchive safety and the selected game's validation.
audit-aiArchive safety and the AI metadata audit.

The Sims 4

  • .package files (DBPF 2.1): signature, header, index bounds and size, resource ranges, and duplicate keys. Resource contents are not decoded.
  • .ts4script files: opened as a ZIP, .py and .pyc entries listed, compiled-code header checked. Script contents are not analyzed or executed.
  • No standard Sims 4 manifest is assumed, so dependencies and versions are not extracted.

inZOI

A root mod_manifest.json marks a candidate mod, not a valid package. There is no official specification behind these checks; they are based on observed sample packages.

  • JSON syntax and field types are checked. Observed fields are never required.
  • Identity, author, version, description, declared dependencies, and game-version metadata are reported as written. Dependencies and compatibility are not verified.
  • FileChecksums shape, path safety, and listed-file existence are checked. Digests are NOT CHECKED: the algorithm couldn't be established, so none is guessed.
  • .pak, .ucas, and .utoc files are recognized as Unreal content containers and inventoried, but their internals are not inspected.
  • Unrelated folders, such as mod-manager state, are reported as unrecognized rather than invalid. Point ModManifest at one mod folder at a time.
🛡 modmanifest.safety ARCHIVES & METADATA

Archive safety & AI metadata audit

🛡 Archive and folder safety

Checks cover path traversal and absolute paths, drive letters and alternate streams, backslashes, duplicate and case-colliding entries, symlinks and special files, entry count, total and per-entry size, compression ratio, signature mismatch, encrypted entries (reported as unsupported), and nested archives (listed, not opened). Limits are configurable with --max-entries, --max-total-mb, --max-entry-mb, and --timeout.

✦ AI metadata audit

Reports AI-related indicators found in JSON, TOML, YAML, and XML manifests, text and Markdown notes, PNG text chunks, XMP, and selected EXIF fields. Indicators fall into three categories: explicit declaration, tool reference, and ambiguous indicator. C2PA support is detection only: possible structures are reported, never parsed or signature-validated.

An AI-related metadata reference is not proof that a mod was AI-generated, and finding nothing doesn't prove AI was absent. Metadata may be absent, incomplete, or removed. AI indicators never change the exit code.

◇ modmanifest.reports JSON SCHEMA 1

Reports & limitations

◇ Statuses and JSON

Findings are PASS, WARNING, ERROR, UNSUPPORTED, or NOT CHECKED (NOT_CHECKED in JSON). Each carries a stable code and an evidence basis, so unverified conditions stay visible. Add --json for stable, machine-readable output using schema_version: 1. Reports use base names, never absolute paths.

Exit codeMeaning
0Scan complete, no ERROR findings.
1One or more ERROR findings.
2Invalid arguments or missing path.
3Incomplete scan, or validate recognized nothing.

Limitations

  • ModManifest is not an antivirus, malware scanner, official game validator, or runtime compatibility tester.
  • A completed inspection doesn't establish that a mod is safe, authentic, compatible, or functional in-game.
  • 7z, RAR, and other archive formats are listed, not opened. Scripts are checked for static risk indicators only and are never executed. Binary game data is not decoded.

Install & links

📦 ModManifest v0.1.1 release →

Requires Python 3.11 or newer. ModManifest v0.1.1 is published on PyPI and as GitHub Release assets. 

python -m pip install modmanifest
modmanifest inspect "./MyMod"

Or download the wheel or source archive from the release assets and install the wheel (pip install modmanifest-0.1.1-py3-none-any.whl), or install from source: 

git clone https://github.com/CyberStudiosTM/ModManifest.git
cd ModManifest
pip install .
