✧ creative_direction.txt STUDIO NOTES

A studio with many windows.

CyberStudios isn't limited to one game, one application, or one kind of experience. It's an umbrella for creative software projects that can look, feel, and behave differently while belonging to the same studio.

The studio's creative identity is shaped by Cy, whose work spans game design, coding, digital art, customization, and experimental web experiences.

Some creations are cozy. Others are technical, immersive, or unusual. What connects them is an interest in making digital experiences feel more expressive, personal, and worth exploring.

⌘ identity_reference.txt DESIGN LANGUAGE

One universe. Different identities.

The CyberStudios Wiki uses a dreamy digital-desktop aesthetic with pastel windows, rounded panels, soft gradients, and playful interface details.

VISUAL AESTHETIC

Cybercore

A pastel, nostalgic digital aesthetic built around pinks, lavender, soft blues, gentle gradients, and retro-computing influences.

GAMEPLAY TECHNOLOGY

CyberCore Gameplay

A separate, developing framework for inZOI gameplay modules, shared context, memory, and compatible integrations.

These names have different meanings. The studio's visual aesthetic is not the same product as the CyberCore Gameplay framework.
? studio_faq.txt QUESTIONS

A few little questions.

Is CyberStudios just a desktop pet project?

No. Byte.exe is one CyberStudios creation. The studio also includes creative tools, gameplay systems, and experimental software projects.

Are all CyberStudios projects connected?

Not necessarily. Projects share a studio identity but can remain independent applications or systems. Technical integrations depend on each project's design.

What is the relationship between Byte and the Bytes?

Bytes is the digital companion product line. Byte.exe features the first Byte, a pixel cat named Byte.

Where can I explore the source code?

Visit the CyberStudios GitHub repository to browse available project source code and documentation.
