# ✧ Cybercore Cotton Candy: Vivid

**A vibrant pastel VS Code customization preset by CyberStudios.**

*Your development environment deserves a little color.*

Cybercore Cotton Candy: Vivid transforms Visual Studio Code into a nostalgic, candy-colored workspace inspired by **Cybercore**, the original CyberStudios aesthetic blending pastel vaporwave, dreamy Y2K technology, Frutiger Aero influences, and digital nostalgia.

Vivid is the more saturated alternative to **Cybercore Cotton Candy: Soft**, offering stronger syntax color separation while preserving the same dreamy pink-and-lavender interface.

![Cybercore Cotton Candy Vivid Preview](vividpreview.png)

## ✧ Features

- 🌸 **Cotton-Candy Interface:** Baby-pink sidebars, lavender tabs, and pearl-white editor backgrounds.
- 💜 **Vivid Syntax Highlighting:** Richer orchid pinks, violets, periwinkle blues, and muted aqua accents.
- 🫧 **Powder-Blue Terminal:** A fully coordinated terminal with custom ANSI colors.
- ✨ **Enhanced Language Coloring:** Custom TextMate and semantic highlighting rules for JavaScript, TypeScript, HTML, CSS, JSON, and other supported languages.
- 🎀 **Matching UI Details:** Coordinated buttons, notifications, scrollbars, selection highlights, and status bars.
- ☁️ **Comfortable Light Mode:** Designed for users who enjoy bright, colorful coding environments.

## ✧ Installation

### Requirements

- [Visual Studio Code](https://code.visualstudio.com/)
- [GitHub Theme](https://marketplace.visualstudio.com/items?itemName=GitHub.github-vscode-theme) extension

### Setup

1. Install Visual Studio Code and the GitHub Theme extension.
2. Download or open the `settings.json` file in this directory.
3. Open VS Code.
4. Press `Ctrl + Shift + P`.
5. Search for **Preferences: Open User Settings (JSON)**.
6. Back up your existing settings.
7. Copy the contents of the Vivid `settings.json` into your user settings, or merge its properties with your existing configuration.
8. Save with `Ctrl + S`.

The preset uses **GitHub Light Default** as its base color theme.

**Important:** This preset customizes VS Code user settings. It is not a standalone theme extension, so users must install the GitHub Theme extension separately.

## ✧ Vivid vs. Soft

Cybercore Cotton Candy comes in two variants:

| | Vivid | Soft |
|---|---|---|
| Syntax colors | Richer, more saturated | Gentle, muted pastels |
| Visual style | Colorful and expressive | Airy and dreamy |
| Interface | Pink, lavender, and pearl | Pink, lavender, and pearl |
| Recommended for | Stronger color separation | Subtle pastel highlighting |

**Both variants use the same Cybercore-inspired interface.** The primary difference is the syntax palette.

Explore the Soft variant in the sibling `soft/` directory.

## ✧ Customization

The theme is fully customizable through `settings.json`.

- `workbench.colorCustomizations` controls interface colors.
- `editor.tokenColorCustomizations` controls TextMate syntax highlighting.
- `editor.semanticTokenColorCustomizations` controls semantic syntax highlighting.
- `editor.fontFamily` and `editor.fontSize` control typography.

Your results may vary slightly depending on the programming language, installed extensions, and editor configuration.
